# DRAGON BALL CALCULATOR

Android calculator project built with Java and Gradle. GitHub Actions builds a debug APK automatically.

## Build
1. Upload the contents of this folder to a GitHub repository.
2. Open the **Actions** tab.
3. If prompted, allow GitHub Actions.
4. Run **Build Dragon Ball Calculator APK** or push a commit.
5. Open the successful workflow run and download the artifact named `Dragon-Ball-Calculator-APK`.
6. Extract the ZIP and install `app-debug.apk` on Android.

The first version includes a themed calculator UI and character-inspired number labels. Add your own licensed Dragon Ball artwork later in `app/src/main/res/drawable/`.
